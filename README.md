# 🌾 Smart Agri Connect

Smart Agri Connect is a modern web platform designed to bridge the gap between farmers and consumers through a digital marketplace. The application enables farmers to showcase and sell agricultural products directly, helping eliminate intermediaries while promoting fair pricing and sustainable farming.

🌐 **Live Demo:** https://smart-agri-connect-gamma.vercel.app/

---

## ✨ Features

- 🌱 Farmer Registration & Login
- 🛒 Browse Agricultural Products
- 🥬 Product Listing & Management
- 🔍 Search & Filter Products
- 🛍️ Add to Cart
- 💳 Order Management
- 📦 Product Categories
- 📱 Fully Responsive Design

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/praveenjaisingh/smart-agri-connect.git
```

### Navigate to the Project

```bash
cd smart-agri-connect
```

### Configure the Database

1. Start **Apache** and **MySQL** using XAMPP.
2. Create a new MySQL database.
3. Import the SQL file from the `database` folder.
4. Update your database credentials in `config.php`.

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "smart_agri_connect";
```

---

## ▶️ Run the Application

1. Move the project folder to the XAMPP `htdocs` directory.
2. Start Apache and MySQL.
3. Open your browser and visit:

```
http://localhost/smart-agri-connect/
```
